### Módulos y Entregas de la Unidad

1. **[Protocolo Individual — Buscador de Números de Identificación](./protocolo-individual/)**
   - **Ejercicio 4**: Implementación manual y estudio comparativo de *Búsqueda Lineal Tradicional* y *Búsqueda Lineal con Centinela*.
   - Proyecto modular en Java con Maven, menú interactivo por consola, validación de casos de prueba (inicio, centro exacto, fin, inexistente y repetidos), análisis formal de complejidad asintótica ($O(1)$ y $O(n)$) y banco experimental multiescala ($10.000$, $100.000$ y $1.000.000$ de registros).
